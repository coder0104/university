# Parser fixtures

These are excerpts from public JinhakApply / Uway competition pages inspected for this project. Only requested departments are relevant. HUFS/UOS fragments are normalized table excerpts; Ewha/KHU retain selected source row markup. They are test inputs, not live source pages, and are excluded from the Pages artifact.

The captured current values are the 2026-09-10 10:00 KST announcement. `khu-final.html` is the verified 2024 admission-year final table. The UOS announcement includes a future final-publication notice specifically to prevent mistaking it for a published final result.

The tests cover current aliases and exact track selection, source/year verification, final versus scheduled announcement, ambiguous row rejection, duplicate suppression, preservation of prior observations, and data arithmetic. They do not claim a successful GitHub-hosted network fetch or deployment.
